# StoreCanvas

App Store / Google Play に掲載する画像を制作するための Web ツールです。
掲載先と作りたい素材を選ぶだけで対応サイズのキャンバスを作成し、Figma のような操作でデザインして、まとめて書き出せます。

**デモ:** https://yuuyuu86.github.io/StoreCanvas/

## 特長

- **ストア別サイズプリセット** — 掲載先 → 素材 → 端末 → 向き を選ぶだけ。サイズを調べずに制作を始められます
- **連結スクリーンショット** — 複数枚を 1 枚の横長キャンバスとして編集。端末や文字を境界にまたがって配置でき、書き出し時にストア用の画像へ自動分割します
- **ホワイトボード＋フレーム** — 1つのプロジェクトが大きなホワイトボード。フレームツール（F）でドラッグして自由サイズのフレームを作成、または右パネルのストア掲載用サイズ一覧からドラッグ＆ドロップで配置、タイトルをドラッグして移動、要素をドラッグで別フレームへ移動
- **リアルな iPhone モックアップ** — 「iPhone ×2（Duo）」で2台並びも1クリック。チタンフレーム・サイドボタン・Dynamic Island・映り込み。カラーも選択可能（Android / iPad / Android タブレットも対応）
- **ドラッグ＆ドロップではめ込み** — 画像ファイルやキャンバス上の画像を端末の上にドロップすると画面にはめ込み
- **プレビュー** — 掲載順・画像間の余白を含めたストアでの見え方を確認
- **一括書き出し** — 書き出し前チェック（サイズ・形式・はみ出し・分割数）付きで ZIP ダウンロード

| 分類 | 内容 |
| --- | --- |
| プロジェクト | 作成・名前変更・複製・削除、検索、最終更新日時、自動保存（IndexedDB）と保存状態表示 |
| プリセット | App Store（iPhone 6.9"/6.5"/6.3"/5.5"、iPad 13"/12.9"/11"、アイコン）、Google Play（スマホ、7"/10" タブレット、Chromebook、アイコン、フィーチャーグラフィック）、その他（OGP、X、Instagram など）、任意サイズ |
| 編集 | テキスト・画像・長方形・楕円・背景（単色/グラデーション）・端末モックアップ、移動・拡縮・回転、複数選択（範囲選択）、コピー/貼り付け/複製/削除、元に戻す/やり直し、重なり順、グループ化、整列・均等配置、スナップとガイド、ズーム |
| レイヤー | 一覧、ドラッグで重なり順変更、名前変更、表示/非表示、ロック |
| ページ | 追加・削除・複製、サムネイル、ドラッグ並び替え、名前変更、複数選択、連結グループの作成・解除・ページ数変更 |
| テンプレート | シンプル / ポップ / ゲーム / 仕事効率化 / 天気 / 写真・動画、雰囲気・種類（単体/連結）で絞り込み |
| 書き出し | ページ選択、PNG/JPEG、連結の自動分割、`01_ページ名.png` 形式の連番ファイル名、ZIP |

## キーボードショートカット

| 操作 | キー |
| --- | --- |
| 元に戻す / やり直し | ⌘Z / ⌘⇧Z |
| コピー / 貼り付け / 複製 | ⌘C / ⌘V / ⌘D |
| 削除 | Delete / Backspace |
| グループ化 / 解除 | ⌘G / ⌘⇧G |
| 前面へ / 最前面へ | ⌘] / ⌘⇧] |
| 背面へ / 最背面へ | ⌘[ / ⌘⇧[ |
| すべて選択 | ⌘A |
| 移動 | 矢印（Shift で 10px） |
| フレーム / 選択 | F / V |
| テキスト / 長方形 / 楕円 / 画像 | T / R / O / I |
| パン | スペース + ドラッグ、ホイール |
| ズーム / 全体表示 / 選択フレーム | ⌘+ ⌘- / ⇧1 / ⇧2、⌘ + ホイール |

画像はファイルのドラッグ＆ドロップやクリップボードからの貼り付けでも追加できます。端末モックアップの上にドロップすると画面にはめ込まれます。

## 開発

```bash
npm install
npm run dev
```

```bash
npm run build
```

技術スタック: React 18 + TypeScript + Vite、Konva（react-konva）、Zustand + Immer、JSZip、idb-keyval

### 構成

```
src/
  presets.ts          ストア別サイズプリセット（確認日 PRESETS_CHECKED_AT）
  templates.ts        テンプレート定義
  store.ts            状態管理・履歴・自動保存
  lib/export.tsx      ページ単位の描画と ZIP 書き出し（連結の自動分割）
  components/
    EditorCanvas.tsx  編集キャンバス（選択・変形・スナップ・分割ガイド）
    BoardNodes.tsx    要素の描画（編集・サムネイル・書き出しで共通）
```

### データモデル

`Board` が編集単位です。`pageNames.length === 1` なら通常のページ、2 以上なら連結グループで、`pageWidth × ページ数` の横長キャンバスとして編集し、書き出し時に `pageWidth` ごとに切り出します。

## 注意事項

- サイズプリセットは各ストアの公開仕様をもとに管理しています（`src/presets.ts`）。ストアの仕様は変更されることがあるため、提出前に公式ドキュメントをご確認ください。
- 書き出し前チェックは制作ミスを減らすためのもので、ストア審査の通過を保証するものではありません。
- ストアでは画像間に余白が表示される場合があり、連結スクリーンショットが完全につながって見えるとは限りません。
- データはブラウザ（IndexedDB）にのみ保存され、外部サーバーへは送信されません。同じプロジェクトを複数のタブで同時に編集すると、最後に保存したタブの内容が残ります。

## セキュリティ

- 本番ビルドには Content-Security-Policy を設定しています（スクリプトは自サイトのみ、画像は埋め込みデータのみ、外部通信は Google Fonts のみ）。
- 読み込める画像は PNG / JPEG / WebP / GIF / AVIF / BMP（25MB・8192px まで）。SVG は受け付けません。
- 保存データは読み込み時に検証し、不正な値や外部 URL の画像は取り除きます。
- GitHub Actions は外部 Action をコミット SHA で固定し、権限を最小限にしています。
